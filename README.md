Project Overview

This project is a GUI-based Job–Resume Matching system that compares a job description with a candidate’s resume using Natural Language Processing (NLP). It extracts relevant keywords, calculates a match score, identifies missing skills, and provides resume improvement suggestions to automate and speed up the recruitment screening process.

🎯 Features

-User-friendly GUI for uploading resume and job description
-Keyword extraction using NLP techniques
-Match score calculation between resume and job description
-Identification of missing skills
-Resume improvement suggestions
-Fast and automated resume screening

🛠️ Technologies Used

-Programming Language: Python
-GUI Framework: Tkinter
-NLP Libraries: NLTK / SpaCy
-Machine Learning: Scikit-learn
-Other Libraries: Pandas, NumPy, Regex
-File Handling: PDF / DOCX text extraction

🧩 System Workflow

-Upload Job Description file
-Upload Resume file
-Text extraction from both files
-Text preprocessing (tokenization, stop-word removal, lemmatization)
-Keyword matching
-Match score calculation
-Missing skills identification
-Display results through GUI

▶️ How to Run the Project
Clone the repository

git clone <repository-link>
Navigate to the project directory

cd job-resume-matching
Install required libraries

pip install -r requirements.txt
Run the main Python file

python main.py

Output
-Match percentage score
-List of missing skills
-Resume improvement suggestions
-GUI-based result display
